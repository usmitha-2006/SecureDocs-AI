# SecureDocs AI

Offline, privacy-first document intelligence using Retrieval-Augmented Generation (RAG).

## Live Demo

https://secure-docs-ai-4.preview.emergentagent.com/

## About

SecureDocs AI is a document intelligence application designed to answer questions from organizational documents using RAG.

## Key Features

- Document-based question answering
- Semantic search
- Document indexing
- Retrieval-Augmented Generation (RAG)
- Grounded responses
- Privacy-focused architecture
- Offline processing mode

## Hackathon

Built for the Masters' Union AI Build Challenge.

## Technology

- RAG
- Vector embeddings
- Semantic search
- Large Language Model (LLM)
- MongoDB
- Emergent
